# Minimal Desktop 使用技巧

一款运行在浏览器里的 iOS 风格桌面，支持应用管理、文件夹、组件、隐私桌面与多端同步。

---

## 🚀 基础操作

### 添加应用
点击桌面上的「**添加应用**」系统图标，输入应用名称和网址即可创建新图标。支持自动抓取网站 favicon 作为图标。

### 打开应用
**单击**任意应用图标，在新标签页中打开对应网址。

### 移动图标
**长按**图标（约 0.5 秒）进入拖拽模式，拖至目标位置后松手完成移动。拖动到页面边缘会自动切换到相邻页。

### 切换页面
左右滑动桌面，或点击底部的**分页指示点**跳转到指定页。

### 右键菜单（桌面端）
在图标上**右键单击**可快速访问「编辑」「删除」「移入文件夹」等操作，无需进入长按模式。

---

## 📁 文件夹

### 创建文件夹
将一个图标**拖拽到另一个图标上方**并悬停约 0.8 秒，两者会自动合并为文件夹。

### 打开 / 关闭文件夹
单击文件夹图标展开内容；点击文件夹外部区域或按 Esc 关闭。

### 重命名文件夹
打开文件夹后，**长按**文件夹标题（名称区域）即可进入编辑状态，输入新名称后回车保存。

### 从文件夹移出应用
打开文件夹后，**长按**内部应用图标，拖出到文件夹外的桌面区域即可。

### 文件夹容量
单个文件夹最多容纳 **9 个**应用。超出上限时无法再拖入。

## 🔒 隐私桌面

### 进入隐私桌面
点击底部分页指示区左侧的**🔒 锁形按钮**，首次使用需设置 PIN 码。

### 设置 / 修改 PIN
在「设置 → 隐私桌面」中设置或修改 6 位 PIN 码。PIN 通过 AES-256-GCM 加密存储，无法找回，请牢记。

### 将应用移入隐私桌面
长按图标进入拖拽模式，将图标拖拽到底部**锁形按钮区域**，解锁后图标会进入隐私桌面。

> **注意**：隐私桌面未解锁时，拖入操作会自动中止并跳转到解锁页面，图标保留在原位。

### 将应用移回普通桌面
解锁隐私桌面后，长按隐私页内的图标并拖拽到普通桌面页即可。

### 错误次数锁定与安全边界
连续输入错误 PIN 5 次后，隐私桌面将锁定 **60 秒**。新建/修改的 vault 使用 PBKDF2-SHA-256（600,000 次迭代）派生密钥并通过 AES-256-GCM 加密；旧版 100,000 次迭代的 vault 仍可解锁。

> **安全提示**：6 位 PIN 适合防止日常误触，并不能替代高熵密码。拿到加密备份的攻击者仍可离线尝试 PIN，因此请保持 GitHub 备份仓库为私有，并保护好设备和 GitHub 账号。

## 🧩 桌面组件

默认桌面包含两个组件，均可在「设置 → 组件管理」中启用/隐藏，并可像桌面项目一样拖动到有足够空间的位置：

| 组件 | 功能 |
|------|------|
| **时钟组件** | 实时显示当前时间与日期 |
| **搜索组件** | 快速搜索，支持切换搜索引擎 |

### 切换搜索引擎
在「**设置 → 搜索引擎**」中选择内置引擎（百度 / Bing / Google 等），或添加自定义引擎（需填入含 `{q}` 占位符的 URL 模板）。

## ⚙️ 设置

点击桌面上的「**设置**」系统图标打开设置面板。

### 外观样式
- **磨砂玻璃（Glassmorphism）**：默认风格，图标背景半透明模糊
- **新拟态（Neumorphism）**：浅色凸起质感

### 壁纸
- 上传本地图片或 GIF 作为壁纸
- 本地图片和视频通过 IndexedDB 持久化，刷新后可自动恢复
- 开启「叠加色彩滤镜」可为壁纸添加极光、日落等色调

### 图标与布局
- **图标大小**：拖动滑块调整（建议 40–56px）
- **每行图标数**：4 列或 5 列
- **每页行数**：1–16 行；启用跨行组件时，下限会自动提升到该组件所需行数
- **撤销 / 重做**：普通桌面支持 `Ctrl/Cmd+Z` 撤销，以及 `Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`）重做

### 添加 / 删除页面
在设置中点击「**添加页面**」可新增空白桌面页。

## ☁️ 多端同步

Minimal Desktop 支持通过 **GitHub 私有仓库**同步桌面数据，在不同设备间保持一致。

### 配置步骤
1. 点击「**同步**」系统图标打开同步设置
2. 推荐创建 **Fine-grained Personal Access Token**，仅为备份仓库授予 Contents 读写权限
3. Token 只保存在当前浏览会话（`sessionStorage`），关闭会话后需要重新输入
4. 点击「**立即上传**」保存当前桌面和加密隐私 vault 到云端

恢复云端数据时会先显示差异摘要；只有点击「确认恢复」后才会覆盖本地桌面和对应的隐私 vault。

### 同步策略

| 模式 | 说明 |
|------|------|
| 手动 | 仅在点击「立即上传 / 下载」时触发 |
| 数据变更时自动上传 | 普通桌面或隐私 vault 变化后防抖上传 |

> **冲突保护**：同步会记录上一次远端分支 HEAD。如果另一台设备先更新了备份，本机上传会停止并要求先下载，不会静默覆盖远端新版本。

## 🧩 浏览器扩展

项目同时提供 Chrome / Firefox MV3 构建。运行 `pnpm build:ext` 后产物位于 `dist-ext/`；Chrome 可在“扩展程序 → 开发者模式 → 加载已解压的扩展程序”中选择该目录。扩展包含新标签页桌面、剪藏弹窗和后台搜索建议代理。

Web 版默认不执行第三方 JSONP 搜索建议脚本。如需 Web 搜索建议，可在构建时把 `VITE_SUGGEST_API_URL` 指向同源 JSON API；响应格式为 `{ "suggestions": ["..."] }` 或 `{ "data": ["..."] }`。

## 🛠️ 本地开发

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
```

`pnpm check` 会依次执行 TypeScript、Biome、Vitest、Web 构建和扩展构建，CI 使用同一组质量门禁。

后续演进计划见 [`docs/ROADMAP.md`](docs/ROADMAP.md)；安全问题报告方式见 [`SECURITY.md`](SECURITY.md)。

## 💡 快捷技巧

- **快速编辑**：右键图标 → 编辑，无需长按进入拖拽模式
- **批量整理**：先建好文件夹，再逐一将图标拖入
- **隐私图标排序**：在隐私桌面内也支持长按拖拽重新排列
- **壁纸 GIF**：上传动态 GIF 可获得动态桌面效果
- **自定义图标**：编辑应用时可粘贴任意图片 URL 替换默认 favicon
