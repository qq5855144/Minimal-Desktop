# Minimal Desktop

一款运行在浏览器里的 iOS 风格桌面，支持应用管理、文件夹、组件、隐私桌面与多端同步。同时提供 Chrome / Firefox 浏览器扩展（新标签页）。

## 基础操作

### 添加应用

点击桌面上的「添加应用」图标，输入应用名称和网址即可创建新图标。支持自动抓取网站 favicon 作为图标。

### 打开应用

单击任意应用图标，在新标签页中打开对应网址。

### 移动图标

按住图标约 0.5 秒完成长按识别：普通应用与文件夹会同时显示操作菜单；继续移动手指即切换为拖拽并自动关闭菜单，拖至目标位置后松手。长按前的滑动不会误启动拖拽，拖到页面边缘会自动切换到相邻页。

### 切换页面

左右滑动桌面，或点击底部的分页指示点跳转到指定页。拖拽项目到最末页边缘会按需创建页面；页面清空后会自动回收。

### 长按菜单

长按后保持不动即可访问应用的「编辑」「删除」，或文件夹的「重命名」「解散」。按 `Esc` 或点击菜单外部可关闭。

## 文件夹

- 将图标拖到另一个图标上方并悬停约 0.8 秒，两者自动合并为文件夹
- 单击文件夹图标展开内容；点击外部区域或按 Esc 关闭
- 打开文件夹后点击标题即可重命名
- 长按内部图标后继续移动可在文件夹内排序，拖出到桌面区域即可移出
- 单个文件夹最多容纳 9 个应用

## 隐私桌面

点击底部分页指示区左侧的锁形按钮进入。首次使用需设置 6 位 PIN 码，可在「设置 → 隐私桌面」中修改。

- PIN 经 AES-256-GCM 加密存储，无法找回，请牢记
- 隐私桌面支持文件夹与多页；靠近普通桌面的第一页为 `-1`，继续向左依次为 `-2`、`-3`……
- 长按图标或文件夹后继续拖到左边缘进入已解锁的隐私页，放入空位即可移入；从隐私页拖到右边缘可移回普通桌面
- 在最左隐私页继续边缘拖拽会按需创建新的负页，空隐私页会自动回收并紧凑重编号
- 连续输入错误 PIN 5 次后锁定 60 秒
- 新建 vault 使用 PBKDF2-SHA-256（600,000 次迭代）派生密钥；旧版 100,000 次迭代的 vault 仍可解锁

> 6 位 PIN 适合防止日常误触，不能替代高熵密码。拿到加密备份的攻击者仍可离线尝试 PIN，请保持同步仓库私有并保护好设备。

## 桌面组件

默认桌面包含时钟与搜索两个组件，均可在「设置 → 组件管理」中启用/隐藏，并可拖动到有足够空间的位置。搜索引擎支持内置引擎（百度 / Bing / Google 等）或自定义 `{q}` 占位符模板；在引擎池中长按任意引擎可编辑或删除，包括内置引擎。

## 设置

点击桌面上的「设置」图标打开设置面板。

- 外观：磨砂玻璃（默认）与新拟态两种风格
- 壁纸：支持本地图片 / GIF，通过 IndexedDB 持久化；可选叠加色彩滤镜
- 图标：大小 40–56px、每行 4/5 列、每页 1–16 行
- 撤销/重做：`Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`），最多 50 步
- 页面：由边缘拖拽按需创建，空页自动回收

## 多端同步

通过 GitHub 私有仓库同步桌面数据（含加密隐私 vault、外观设置和壁纸）。本地图片或视频壁纸会作为独立媒体文件保存，并在下载时执行 SHA-256 完整性校验；桌面数据变化时可复用未变化的壁纸文件，避免重复上传。

1. 点击「同步」图标打开同步设置
2. 推荐使用 Fine-grained Personal Access Token，仅授予备份仓库 Contents 读写权限
3. Token 默认只保存在当前浏览会话（`sessionStorage`）；勾选「保持登录」后可持久化，下次打开自动连接
4. 「立即上传」保存到云端；恢复前会显示差异摘要，确认后才覆盖本地

同步策略支持手动或数据变更时防抖自动上传。上传会在标签页内及同源标签页之间串行执行，并以备份文件 blob 作为并发基线；会话 Token 失效后重新连接同一仓库仍会保留已确认基线，连续拖拽、手动/自动同步交错及 README 等无关提交不会产生误报，相同快照也不会重复创建 commit。引用更新竞态会重新读取最新 HEAD 并再次验证备份文件，确认没有其他设备修改后自动重试。若备份确由其他设备更新，自动同步才会暂停并提供“下载并比较”和“本次覆盖”；用户主动删除远端备份文件后，下次上传会安全重建。

## 浏览器扩展

运行 `pnpm build:ext` 后产物位于 `dist-ext/`。Chrome 在「扩展程序 → 开发者模式 → 加载已解压的扩展程序」中选择该目录。扩展包含新标签页桌面、剪藏弹窗和后台搜索建议代理。

正式版 Release 同时提供 ZIP 与 RSA/SHA-256 签名的 CRX3，当前固定扩展 ID 为
`eebbmnggihhbaeejkhdinnbilelbmaef`。本地签名可先生成 ZIP，再运行：

```bash
node scripts/crx3.mjs pack --zip extension.zip --key extension.pem --out extension.crx
node scripts/crx3.mjs verify --crx extension.crx --manifest dist-ext/manifest.json
```

签名私钥只能放入被忽略的 `.private/` 目录或 GitHub Actions 的 `CRX_PRIVATE_KEY`
Secret，禁止提交到仓库。Chrome 稳定版可能受侧载策略限制；ZIP 开发者模式安装仍作为兼容方案保留。

Web 版默认不执行第三方 JSONP 搜索建议脚本。如需 Web 搜索建议，可在构建时把 `VITE_SUGGEST_API_URL` 指向同源 JSON API；响应格式为 `{ "suggestions": ["..."] }` 或 `{ "data": ["..."] }`。

## 本地开发

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
```

`pnpm check` 依次执行 TypeScript、Biome、Vitest、Web 构建和扩展构建，CI 使用同一组质量门禁。

后续演进计划见 [docs/ROADMAP.md](docs/ROADMAP.md)；安全问题报告方式见 [SECURITY.md](SECURITY.md)。

## 小技巧

- 长按图标后保持不动可编辑；继续移动则无缝切换为拖拽
- 先建好文件夹再逐一拖入，批量整理更快
- 隐私桌面内同样支持长按拖拽排序
- 上传动态 GIF 可获得动态壁纸效果
- 编辑应用时可粘贴图片 URL 替换默认 favicon
