# 天气组件

在设置的「桌面组件」中开启天气，首次开启自动请求浏览器定位权限，授权后直接显示当地天气。扩展版首次点击「允许定位」授予可选权限，后续自动定位。长按卡片可切换小尺寸（2 行 × 2 列）与大尺寸（2 行 × 4 列），也可以拖动位置。扩展时优先保留原位，再寻找空位；没有空间则保留原布局。

点击卡片打开详情：逐小时预报、多日温度折线/列表、日出日落、降水概率及空气质量。默认自动定位，每 30 分钟在页面可见时重新获取位置；定位失败保留已有天气，允许重试或手动选城。手动选择后固定该城市，点击「使用当前位置」恢复自动定位。位置仅保留两位小数，不持续追踪。城市设置和最近一次天气缓存在当前设备；组件位置与尺寸随桌面数据保存。

卡片背景根据当前 WMO 天气码和昼夜状态切换，覆盖晴、多云、阴、雨、雪、雾及雷雨；使用轻量静态纹理，无闪烁动画。未知天气使用中性背景。

定位遵循 [浏览器定位权限](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/getCurrentPosition) 与 [Chrome 扩展权限](https://developer.chrome.com/docs/extensions/reference/permissions-list)，拒绝权限后不会自动反复弹窗。

## 数据来源

直接调用 Open-Meteo 官方 HTTPS API，无需申请 Key：

- [天气 API](https://open-meteo.com/en/docs)
- [城市搜索](https://open-meteo.com/en/docs/geocoding-api)（GeoNames）
- [空气质量 API](https://open-meteo.com/en/docs/air-quality-api)（CAMS）

免费接口用于非商业用途，商用需另行核实官方许可及服务方案。详情页保留数据来源署名。空气质量明确标为美标 AQI，不等同于中国 AQI；降水提示展示预报概率，不提供分钟级降雨承诺。

30 分钟缓存并合并并发请求；手动刷新至少间隔 1 分钟。天气请求设置超时和有限重试，空气质量为可选数据，3 秒超时后不阻塞天气展示。网络失败时保留最近缓存并提示更新时间，缺失值显示占位符。后台标签页不定时刷新。

Open-Meteo 的中国大陆访问速度取决于当地网络，不能保证所有运营商均流畅；需在目标设备和网络上验收。常用城市可以绕过城市搜索服务，缓存减少重复访问。

## 浏览器兼容与城市解析

系统定位失败或超时后，使用高精度模式重试。两次均失败则通过 BigDataCloud 免 Key 客户端接口获取 IP 对应的大致城市，在名称后标注「大致」；网络代理可能影响此结果。拒绝定位权限时不会请求网络粗略定位。浏览器通知权限恢复后会重新尝试，暂时性定位故障不会永久锁死。

定位成功后通过同一接口解析中文城市名；接口失败仍可用已获取的坐标加载天气，显示「附近天气」，不编造城市。仅从用户浏览器请求设备当前位置，不在服务器执行此接口。参考 [官方客户端接口文档](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)。

大卡片使用 Flex 和普通响应式字体尺寸，移除嵌套容器查询，避免部分 Chromium 版本发生左侧内容消失。组件取消外边框和内侧高光。
