# 书签

桌面新增系统入口「书签」，旧桌面升级时自动寻找空位添加，已有入口在文件夹内也不会重复添加。

默认显示所有分组的书签。搜索匹配名称和网址；「更多」可切换分组、新建分组或添加书签。扩展剪藏选择「添加到桌面」或「添加到书签」后打开桌面完成保存。剪藏书签默认进入默认分组。

点击「编辑」后，可选择多个书签，并在底栏全选、移动分组、删除或打开。选择一条时可修改名称和网址。「完成」退出编辑。拖动右侧把手调整顺序，键盘聚焦把手后用上下方向键调整。搜索结果中的全选仅选择当前可见结果。删除前会确认。

本功能管理应用自己的书签，不读取浏览器原生书签。数据与分组保存到桌面数据中，随现有备份同步；数据版本升级至 6，旧版客户端需要更新后读取新版备份。网页批量打开可能被浏览器拦截，需要允许弹出窗口；扩展版使用标签页接口打开。
